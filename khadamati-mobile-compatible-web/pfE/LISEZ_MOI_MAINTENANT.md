## 🆘 Si Vous Ne Connaissez Pas le Mot de Passe

### Option 1 : Réinitialisez-le
Dans MySQL Workbench :
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'nouveau_mot_de_passe';
FLUSH PRIVILEGES;
```

### Option 2 : Essayez ces mots de passe
- (vide)
- `root`
- `mysql`
- `admin`
- `password`

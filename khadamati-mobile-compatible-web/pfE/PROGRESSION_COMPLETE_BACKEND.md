## 📝 ENDPOINTS STANDARDS POUR CHAQUE CONTROLLER

Chaque controller doit exposer les endpoints suivants :

### Endpoints CRUD de Base
- `GET /api/xxx` - Récupérer toutes les entités
- `GET /api/xxx/{id}` - Récupérer une entité par ID
- `POST /api/xxx` - Créer une nouvelle entité
- `PUT /api/xxx/{id}` - Mettre à jour une entité
- `DELETE /api/xxx/{id}` - Supprimer une entité

### Endpoints de Recherche
- `GET /api/xxx/search?q={query}` - Recherche par mot-clé
- `GET /api/xxx/by-code/{code}` - Recherche par code
- `GET /api/xxx/by-type/{type}` - Recherche par type
- `GET /api/xxx/by-status/{status}` - Recherche par statut

### Endpoints Métier Spécifiques
- Selon les besoins de chaque entité (validation, approbation, calculs, etc.)

## 🚀 DÉMARRAGE RAPIDE

### Avec Docker (Recommandé) 🐳

```bash
# Démarrer tout
docker-compose up -d

# Vérifier l'état
docker-compose ps

# Voir les logs
docker-compose logs -f
```

✅ **Frontend** : http://localhost:3000  
✅ **Backend** : http://localhost:8081

### Sans Docker

#### 1️⃣ Backend
```bash
cd spring-backend
./mvnw spring-boot:run
```
✅ http://localhost:8081

#### 2️⃣ Frontend
```bash
cd frontend
npm install  # Première fois
npm run dev
```
✅ http://localhost:3000

### 3️⃣ Navigateur
Ouvrir http://localhost:3000 et explorer !

📚 **Guide Docker complet** : `DEMARRAGE_DOCKER.md`

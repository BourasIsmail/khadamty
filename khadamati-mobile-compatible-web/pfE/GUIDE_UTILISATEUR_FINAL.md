# 👤 Guide Utilisateur Final - Khadamati

**Guide d'utilisation pour les employés** 📖

---

## 🎯 Bienvenue sur Khadamati !

**Khadamati** (خدماتي) est votre plateforme de gestion RH de l'Entraide Nationale. Ce guide vous aidera à utiliser toutes les fonctionnalités disponibles.

---

## 🚀 Première Connexion

### Étape 1 : Recevoir vos Identifiants

Votre responsable RH vous a créé un compte. Vous avez reçu :
- ✉️ **Email** : votre.email@khadamati.ma
- 🔑 **Mot de passe** : Un mot de passe temporaire

### Étape 2 : Se Connecter

1. **Ouvrir le navigateur** et aller sur : http://localhost:3000
2. **Cliquer** sur "Se connecter"
3. **Entrer** votre email et mot de passe
4. **Cliquer** sur "Se connecter"

### Étape 3 : Vérifier votre Email (Première fois uniquement)

🔐 **Pour votre sécurité**, lors de votre première connexion, vous devez vérifier votre email :

1. **Vous recevrez un message** : "Code envoyé à v***e@khadamati.ma (première connexion)"
2. **Vérifier votre boîte email** : Vous avez reçu un code à 6 chiffres
3. **Entrer le code** dans le champ prévu
4. **Cliquer** sur "Vérifier"

✅ **C'est fait !** Vous êtes maintenant connecté.

### Étape 4 : Connexions Suivantes

🎉 **Bonne nouvelle !** Vous n'aurez plus besoin du code OTP.

Les prochaines fois, il suffit de :
1. Entrer votre email et mot de passe
2. Cliquer sur "Se connecter"
3. ✅ Vous êtes connecté immédiatement !

## 🏖️ Gérer vos Congés

### Voir votre Solde de Congés

1. **Cliquer** sur "Mes congés" dans le menu
2. **Vous verrez** :
   - 📊 Solde total de congés
   - ✅ Congés utilisés
   - ⏳ Congés en attente
   - 📅 Congés restants

### Demander un Congé

1. **Cliquer** sur "Nouvelle demande"
2. **Remplir le formulaire** :
   - **Type de congé** : Annuel, Maladie, Exceptionnel, etc.
   - **Date de début** : Premier jour de congé
   - **Date de fin** : Dernier jour de congé
   - **Nombre de jours** : Calculé automatiquement
   - **Raison** : Expliquer brièvement
3. **Cliquer** sur "Soumettre"

✅ **Votre demande est envoyée !** Vous recevrez une notification quand elle sera traitée.

### Suivre vos Demandes

Dans "Mes congés", vous verrez toutes vos demandes avec leur statut :

- 🟡 **En attente** : Votre demande est en cours de traitement
- 🟢 **Approuvée** : Votre congé est validé
- 🔴 **Rejetée** : Votre demande a été refusée (avec raison)

### Annuler une Demande

Si votre demande est encore **en attente**, vous pouvez :
1. **Cliquer** sur la demande
2. **Cliquer** sur "Annuler la demande"
3. **Confirmer** l'annulation

## 📄 Demander des Attestations

### Types d'Attestations Disponibles

- 📋 **Attestation de travail** : Preuve que vous travaillez ici
- 💰 **Attestation de salaire** : Pour les démarches bancaires
- 🏠 **Attestation de résidence** : Pour les démarches administratives
- 📜 **Autre** : Spécifier votre besoin

### Faire une Demande

1. **Cliquer** sur "Mes attestations" dans le menu
2. **Cliquer** sur "Nouvelle demande"
3. **Remplir le formulaire** :
   - **Type d'attestation** : Choisir dans la liste
   - **Raison** : Expliquer pourquoi vous en avez besoin
4. **Cliquer** sur "Soumettre"

✅ **Votre demande est envoyée !** Le service RH la traitera rapidement.

### Récupérer votre Attestation

Quand votre demande est **approuvée** :
1. **Vous recevrez une notification**
2. **Aller dans "Mes attestations"**
3. **Cliquer** sur "Télécharger" pour obtenir le document PDF

## 👤 Gérer votre Profil

### Voir vos Informations

1. **Cliquer** sur "Mon Profil" dans le menu
2. **Vous verrez** :
   - 📧 Email
   - 📱 Téléphone
   - 🏢 Département
   - 💼 Poste
   - 📅 Date d'embauche
   - 🏠 Adresse
   - 🚨 Contact d'urgence

### Modifier vos Informations

1. **Cliquer** sur "Modifier"
2. **Changer** les informations que vous voulez
3. **Cliquer** sur "Enregistrer"

⚠️ **Note** : Certaines informations (email, département, poste) ne peuvent être modifiées que par le service RH.

### Changer votre Mot de Passe

1. **Aller dans "Mon Profil"**
2. **Cliquer** sur "Changer le mot de passe"
3. **Entrer** :
   - Mot de passe actuel
   - Nouveau mot de passe
   - Confirmer le nouveau mot de passe
4. **Cliquer** sur "Enregistrer"

🔒 **Conseil de sécurité** : Utilisez un mot de passe fort avec au moins 8 caractères, incluant des lettres, chiffres et symboles.

## 🆘 Aide et Support

### Problèmes Courants

#### Je ne reçois pas le code OTP

**Solutions** :
1. Vérifier votre dossier **spam**
2. Attendre 1-2 minutes (le mail peut prendre du temps)
3. Cliquer sur **"Renvoyer le code"**
4. Si le problème persiste, contacter le service RH

#### J'ai oublié mon mot de passe

**Solution** :
1. Cliquer sur **"Mot de passe oublié ?"** sur la page de connexion
2. Entrer votre email
3. Vous recevrez un lien pour réinitialiser votre mot de passe
4. Si vous ne recevez pas le mail, contacter le service RH

#### Ma demande de congé est bloquée

**Solutions** :
1. Vérifier que vous avez assez de jours de congé disponibles
2. Vérifier que les dates sont correctes
3. Vérifier que vous n'avez pas déjà une demande en attente pour ces dates
4. Si le problème persiste, contacter le service RH

#### Je ne vois pas mes informations

**Solutions** :
1. Rafraîchir la page (F5 ou Ctrl + R)
2. Se déconnecter et se reconnecter
3. Vider le cache du navigateur
4. Si le problème persiste, contacter le service IT

## 🔒 Sécurité et Confidentialité

### Protéger votre Compte

✅ **Bonnes pratiques** :
- Ne partagez **jamais** votre mot de passe
- Utilisez un mot de passe **fort et unique**
- Changez votre mot de passe **régulièrement**
- Déconnectez-vous quand vous quittez votre poste
- Ne laissez pas votre session ouverte sur un ordinateur partagé

❌ **À éviter** :
- Utiliser le même mot de passe que d'autres sites
- Écrire votre mot de passe sur un papier
- Partager votre compte avec quelqu'un d'autre
- Cliquer sur des liens suspects dans des emails

### Confidentialité de vos Données

🔐 **Vos données sont protégées** :
- Toutes les communications sont **chiffrées**
- Vos informations personnelles sont **confidentielles**
- Seul le service RH et les administrateurs autorisés peuvent voir vos données
- Vos mots de passe sont **cryptés** et ne peuvent pas être lus

## ❓ FAQ (Questions Fréquentes)

### Q1 : Combien de jours de congé ai-je par an ?

**R** : Cela dépend de votre contrat. Consultez votre solde dans "Mes congés" ou contactez le service RH.

### Q2 : Combien de temps pour traiter ma demande de congé ?

**R** : En général, 2-3 jours ouvrables. Les demandes urgentes peuvent être traitées plus rapidement.

### Q3 : Puis-je annuler un congé déjà approuvé ?

**R** : Oui, mais vous devez contacter le service RH directement. Vous ne pouvez pas l'annuler vous-même dans l'application.

### Q4 : Combien de temps pour recevoir mon attestation ?

**R** : En général, 1-2 jours ouvrables après approbation.

### Q5 : Puis-je demander plusieurs attestations en même temps ?

**R** : Oui, vous pouvez faire autant de demandes que nécessaire.

### Q6 : Que faire si je vois une erreur dans mes informations ?

**R** : Contactez le service RH pour corriger les informations. Certaines informations ne peuvent être modifiées que par le RH.

### Q7 : Mon compte est-il sécurisé ?

**R** : Oui, toutes les données sont chiffrées et protégées. Assurez-vous d'utiliser un mot de passe fort et de ne jamais le partager.

### Q8 : Puis-je utiliser Khadamati sur plusieurs appareils ?

**R** : Oui, vous pouvez vous connecter depuis n'importe quel appareil (ordinateur, tablette, téléphone).
